# Handoff Brief Template

Use this when parallel work will continue in fresh agent threads or separate worker windows.

```markdown
# Handoff Brief

## Original Goal
{What the overall project is trying to accomplish}

## Shared Context
{Facts, prior decisions, constraints, vocabulary, and assumptions every worker needs}

## Relevant Files Or Data
- {Path, URL, dataset, artifact, or command output}

## Non-Goals
- {Work that should stay out of scope}

## Worker Rules
- Read this brief before starting the assigned subtask.
- Do not change ownership boundaries unless the coordinator asks.
- Report blockers, uncertainty, and conflicts explicitly.
- Return output in the requested format so results can be merged.

## Final Deliverable
{The shape of the merged result}
```
