# Decomposition Patterns by Domain

## Software Engineering

### Code Review
- **By concern**: Logic / Security / Performance / Style / Documentation
- **By component**: Frontend / Backend / Database / API / Infrastructure
- **By layer**: Data layer / Business logic / Presentation layer

### Feature Development
- **By stack layer**: UI components / API endpoints / Data models / Tests
- **By user flow**: Authentication / Core feature / Edge cases / Admin tools
- **By platform**: Web / Mobile / Desktop / API

### Bug Investigation
- **By hypothesis**: Data issue / Logic error / Environment / Integration
- **By scope**: Reproduction / Root cause / Fix / Verification

## Content Creation

### Report Writing
- **By section**: Executive summary / Methodology / Findings / Recommendations / Appendices
- **By audience**: Technical / Business / Executive / Public
- **By topic**: Background / Analysis / Comparison / Conclusion

### Marketing Campaign
- **By channel**: Social media / Email / Blog / Video / Landing page
- **By funnel stage**: Awareness / Consideration / Conversion / Retention
- **By persona**: Segment A / Segment B / Segment C

## Research & Analysis

### Competitive Analysis
- **By dimension**: Product features / Pricing / Market share / Customer sentiment
- **By competitor**: Company A / Company B / Company C / Market leader
- **By methodology**: Qualitative / Quantitative / SWOT / Benchmarking

### Data Analysis
- **By dataset**: Source A / Source B / Source C
- **By technique**: Descriptive / Diagnostic / Predictive / Prescriptive
- **By metric**: Growth / Retention / Revenue / Efficiency

## Business Operations

### Process Improvement
- **By phase**: Current state / Gap analysis / Solution design / Implementation plan
- **By stakeholder**: Customer / Operations / Finance / Compliance
- **By impact**: Quick wins / Medium-term / Strategic initiatives

### Strategic Planning
- **By horizon**: Short-term (0-6mo) / Medium-term (6-18mo) / Long-term (18-36mo)
- **By function**: Product / Engineering / Marketing / Sales / Operations
- **By objective**: Growth / Efficiency / Risk reduction / Innovation

## Creative Work

### Design Projects
- **By element**: Visual identity / UI components / Interaction patterns / Content
- **By platform**: Web / Mobile / Print / Environmental
- **By iteration**: Concept / Refinement / Production / Handoff

### Video Production
- **By phase**: Script / Storyboard / Filming / Editing / Post-production
- **By scene**: Setup / Conflict / Resolution / Call-to-action
- **By output**: Full video / Trailers / Social clips / Thumbnails

## When NOT to Decompose

- **Unified creative vision**: Poetry, brand voice, single-author narrative
- **Tight feedback loops**: Tasks requiring rapid iteration between steps
- **Unknown unknowns**: Exploratory work where the path is unclear
- **Coordination overhead > parallel gain**: Small tasks with complex merge needs
